
# 🇵🇰 PakInsight – Pakistan City Data Intelligence

Find the right city for your lifestyle with clear insights into weather, living costs and economic opportunities across Pakistan.

## 📌 Project Overview

PakInsight is an end-to-end data analytics project that collects, cleans, analyzes, and visualizes public data about Pakistani cities.

It combines weather information, cost-of-living data, and economic indicators to uncover meaningful insights and help users compare cities through data-driven analysis.

## 🎯 Key Features

- Weather analysis and city comparison
- Cost-of-living analysis
- Economic indicators analysis
- Interactive dashboard using Streamlit
- SQL-based data analysis
- Data visualization and insights

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- SQL / MySQL
- Streamlit
- APIs
- Web Scraping

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd pakinsight-data-intelligence
```

### 2. Create and activate environment

```bash
conda create -n pakinsight python=3.11
conda activate pakinsight
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure MySQL

Create a MySQL database named `pakinsight` and configure your local database connection.

### 5. Run the application

```bash
cd app
streamlit run app.py
```
